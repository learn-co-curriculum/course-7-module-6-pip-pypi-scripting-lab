
# Module Lab: Automating Python Projects with Pip, PyPi & Scripting

A lightweight CLI automation tool that generates timestamped log files.

## Features

- Generates log files with this pattern `log_YYYYMMDD.txt`
-Validates input (must be a list)
- Tracks dependencies via `requirements.txt`

### setup

```bash

pip install -r requirements.txt 

```

### Usage

```bash

python lib/generate_log.py 

```
